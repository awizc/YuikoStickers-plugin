# YuikoStickers

Snow Family Yuiko 이모지를 Discord 입력창에서 선택하는 BetterDiscord 플러그인입니다.

## 사용 방법

- 이모지 **우클릭**: 전송 대기 목록에 선택한 순서대로 추가합니다. 같은 이모지를 여러 번 넣을 수 있습니다.
- 이모지 **좌클릭**: 대기 중인 이모지와 마지막으로 클릭한 이모지를 함께 전송합니다.
- 전송 형식은 `.이모지1.이모지2.이모지3`입니다. 쉼표로 구분된 별칭이 있으면 첫 번째 이름을 사용합니다.
- 하단 썸네일의 **×**로 개별 선택을 취소하고, **전체 비우기**로 대기 목록을 비웁니다.
- 패널을 닫으면 대기 목록과 검색어가 초기화됩니다.
- 정렬 버튼 왼쪽의 작은 버튼을 누르면 즐겨찾기 방식을 **1초 이상 길게 누르기 / Shift+우클릭**으로 전환합니다. 선택한 방식은 저장됩니다.
- ⚙에서 표시할 그룹을 선택합니다. 그룹과 즐겨찾기는 드래그로 순서를 바꿀 수 있습니다.

채팅 이미지 위의 GIF 배지는 플러그인을 사용하는 화면에서 숨깁니다. 이미지의 애니메이션은 유지됩니다.

## 업데이트 확인

현재 확인 시점은 플러그인 시작 시, 매 정시, 패널을 열 때입니다. 패널을 통한 확인에는 5분 간격 제한이 있습니다. GitHub의 `@version`이 설치 파일보다 높을 때 업데이트합니다.

이 방식은 실시간 푸시가 아닙니다. GitHub 응답 캐시나 클라이언트의 파일 재로드 상태에 따라 반영이 늦을 수 있습니다. 품질 개선 작업에서는 확인 시점과 다운로드 방식을 변경하지 않았습니다.

## 개발 및 검증

실제 플러그인은 `YuikoStickers.plugin.js` 한 파일입니다. `package.json`의 의존성은 개발 테스트에만 사용하며, 플러그인을 실행하는 데 `npm install`은 필요하지 않습니다.

테스트 환경: Node.js 24, jsdom 30.1.1.

```powershell
npm ci
npm run check
npm test
```

테스트는 Discord DOM, BetterDiscord API, 네트워크 응답, 타이머와 업데이트 파일 쓰기를 대체 환경에서 검사합니다. 실제 메시지 전송, 실제 설치 파일 쓰기, GitHub 업로드는 수행하지 않습니다.

`tests/fixtures/ui-contract.json`은 품질 개선 전 2.17.3의 주요 화면 DOM과 CSS 해시입니다. 조작이나 디자인을 의도적으로 바꾸는 작업이 아니라면 이 기준을 갱신하지 않습니다.

변경 내용과 검증 범위는 [QUALITY_REVIEW.md](QUALITY_REVIEW.md)에 기록했습니다.
